# wheel_speedControl — 陆空两栖机器人底盘控制固件

> **硬件平台**：ESP32-S3-DevKitM-1 · **框架**：Arduino / PlatformIO · **控制周期**：20 ms（50 Hz）

面向**陆空两栖变形机器人**的地面底盘控制固件。ESP32-S3 承担**实时执行层 + 安全层**（电机、编码器、姿态、急停），Jetson Orin Nano 承担**决策层**（SLAM / Nav2 / 视觉），Pixhawk 飞控负责空中动力。典型应用背景为涵洞巡检、光伏热斑检测等无人化巡检场景。

---

## 一、主要特性

| 能力 | 说明 |
|------|------|
| **四轮差速驱动** | TB6612 驱动四路直流电机，左右差速转向 |
| **串级 PID** | 位置环（P+I）→ 速度环（PID），含条件积分抗饱和、微分先行 |
| **坡度自适应** | 由俯仰角实时调整速度上限与速度环增益（爬坡不飞车） |
| **重力前馈** | MPU6050 俯仰角 → PWM 前馈补偿，1 s 线性淡入 |
| **多源控制分流** | ROS2 自动 / 手动遥控 / 自主清扫 / 静止驻车，固定优先级 |
| **自主"弓"字形清扫** | 10 状态机：直行 → 转 90° → 换行 → 反向直行，最多 6 行 |
| **安全模块** | 上电自检、急停、故障降级、看门狗、反馈失控自检 |
| **上下位机通信** | 自定义二进制帧协议，921600 bps，7 B 下行 / 15 B 上行 |
| **MAVLink 桥接** | MAVLink v2 无外部库自实现，急停时自动向飞控发送 disarm |

## 三、硬件与引脚映射

全部引脚定义集中在 [src/config.h](src/config.h)，修改硬件接线只需改这一处。

### 3.1 底盘电机驱动（TB6612，四路独立）

| 轮位 | PWM | IN1 | IN2 |
|------|-----|-----|-----|
| 左前 | GPIO 5 | GPIO 7 | GPIO 6 |
| 左后 | GPIO 48 | GPIO 21 | GPIO 47 |
| 右后 | GPIO 17 | GPIO 8 | GPIO 18 |
| 右前 | GPIO 1 | GPIO 42 | GPIO 2 |

> STBY = GPIO 4。右前电机 IN1 原为 GPIO 37，因该脚在 ESP32-S3-N16R8 模组内部连接 Octal PSRAM，已迁移至 GPIO 42。

### 3.2 其他外设

| 模块 | 引脚 | 说明 |
|------|------|------|
| 霍尔编码器 | L: 15/16，R: 41/40 | 四边沿中断 4 倍频 |
| MPU6050 | SDA 3 / SCL 39 | I²C 地址 0x68 |
| 清洁电机（TB6612 #2） | PWM 9 / STBY 10 | LEDC 通道 4，占空比 128 |
| 遥控接收机 | CH1:14，CH2:13，CH9:12，CH10:11 | PWM 脉宽解码，1000–2000 µs |
| Jetson Orin Nano | RX 44 / TX 43 | UART1 @ 921600，3.3 V TTL 直连 |
| Pixhawk TELEM2 | RX 39 / TX 38 | UART2 @ 57600，MAVLink v2 |

### 3.3 遥控器通道分配

| 通道 | 功能 | 判定阈值 |
|------|------|----------|
| CH1 | 转向摇杆（左右） | 死区 ±50 µs |
| CH2 | 油门摇杆（前后） | 死区 ±80 µs；有效范围 900–2100 |
| CH9 | 飞行 / 地面模式切换 | ≤1700 飞行，>1700 地面 |
| CH10 | 清洁开关 & 自主清扫触发 | >1600 开启 |

### 3.4 ⚠️ 硬件注意事项

- **GPIO 33–37 在 ESP32-S3-N16R8 模组内部连接 Octal PSRAM，严禁外接**，右编码器因此改用 GPIO 40/41。
- ESP32 与 Orin Nano **只接 TX/RX/GND 三根线，不接 VCC**，两边独立供电但必须共地。
- 上电顺序：ESP32-S3 先上电（完成 POST）→ Orin Nano 后上电 → 启动 `serial_bridge`。

## 五、控制模式

所有模式均要求**安全状态非急停**且**处于地面模式（CH9 > 1700）**；飞行模式下电机完全释放、PID 复位。

| 优先级 | 模式 | 启动条件 | 控制方式 |
|:------:|------|----------|----------|
| ① | **ROS2 自主导航** | 下行帧 `mode = 2` 且 200 ms 内有有效帧 | 纯速度环，指令来自 Orin Nano |
| ② | **手动遥控** | CH1/CH2 超出死区，CH2 在 900–2100 | 串级 PID（位置环 + 速度环） |
| ③ | **自主清扫** | 摇杆回中且 CH10 > 1600 | 串级 PID + 弓字形状态机 |
| ④ | **静止驻车** | 以上均不满足 | 位置锁定当前计数，抵抗外力 |
| ⑤ | **急停** | 安全模块触发 | 独立于分流，主动刹车 |

**模式切换要点**

- ROS2 模式下摇杆不抢占控制权；退出时自动对齐位置目标并复位 PID，避免位置环阶跃。
- 下行帧超时 200 ms 未更新 → 自动降级为手动模式，速度归零。
- 空地切换（CH9）沿变时对齐编码器目标、复位 PID、清零前馈，并向飞控发送 arm/disarm。

## 六、PID 参数

控制律：**位置环（外环）→ 速度环（内环）→ PWM**。位置环将位置误差转为速度目标，速度环再转为 PWM 输出。

当前参数（[src/config.h](src/config.h)，2026-08-13 定版）：

| 参数 | 值 | 说明 |
|------|-----|------|
| `KP_P_POS` | 0.7 | 位置环比例。1.2 时与速度环耦合振荡，已下调 |
| `KI_P_POS` | 0.01 | 位置环积分 |
| `KP_V_FLAT` | 1.2 | 平地速度环比例。满速≈147 计数/20 ms，8.5 会立即饱和 |
| `KP_V_SLOPE` | 0.6 | 陡坡附加增益（实际 `kp_v = KP_V_FLAT + slope × KP_V_SLOPE`） |
| `KI_V_SPD` | 0.1 | 速度环积分。1.2 会导致积分饱和 → bang-bang 极限环 |
| `KD_V_SPD` | 0.5 | 速度环微分（微分先行，作用于实际速度） |
| `I_V_LIMIT` | 100 | 速度环积分输出限幅 |
| `ERROR_LIMIT` | 800 | 位置环误差硬限幅（脉冲） |
| `MIN_RPM_FACTOR` | 0.467 | 陡坡时保留的最小速度比 |
| `FF_MAP_MAX` | 45 | 重力前馈 PWM 上限（±45 / 255 ≈ 17.6%） |

**单位约定**：速度单位为「编码器计数 / 20 ms」。编码器 `13 PPR × 4 倍频 × 34 减速比 = 1768 计数/圈`，额定 250 RPM 时满速约 **147 计数/20 ms**。

**手动映射**：油门 `±120`、转向 `±60` 步进/周期（同步放大，保持 0.5 比例）。

**抗积分饱和**：采用条件积分法——输出饱和时若积分与误差同号则暂停累积，异号则正常累积，既防 windup 又保留快速退饱和能力。

## 七、通信协议

### 7.1 上下位机（UART1 ↔ Jetson Orin Nano）

- 波特率 **921600**，8N1，无流控，50 Hz 与控制周期同步
- 校验：帧内前 N-1 字节 XOR

**下行帧（Orin Nano → ESP32，7 B）**

| 偏移 | 字段 | 类型 | 说明 |
|:----:|------|------|------|
| 0 | SYNC | uint8 | 帧头 `0xAA` |
| 1–2 | L_VEL | int16 | 左轮目标速度（计数/周期） |
| 3–4 | R_VEL | int16 | 右轮目标速度 |
| 5 | MODE | uint8 | 0=释放 1=手动 2=ROS2 自主 3=急停 |
| 6 | CHECKSUM | uint8 | 前 6 字节 XOR |

**上行帧（ESP32 → Orin Nano，15 B）**

| 偏移 | 字段 | 类型 | 说明 |
|:----:|------|------|------|
| 0 | SYNC | uint8 | 帧头 `0xBB` |
| 1–4 | ENC_L | int32 | 左编码器累计脉冲 |
| 5–8 | ENC_R | int32 | 右编码器累计脉冲 |
| 9–10 | PITCH | int16 | 俯仰角 ×100（°） |
| 11–12 | FAULT | uint16 | 故障位掩码 |
| 13 | STATE | uint8 | 安全状态枚举 |
| 14 | CHECKSUM | uint8 | 前 14 字节 XOR |

### 7.2 飞控 MAVLink（UART2 ↔ Pixhawk TELEM2）

MAVLink v2（起始字节 `0xFD`），**无外部库依赖，帧编解码自实现**，仅实现需要的 3 条消息：

| 消息 | ID | 用途 |
|------|----|------|
| HEARTBEAT | 0 | 双向维持链路，解析飞控在线与武装状态 |
| COMMAND_LONG | 76 | `MAV_CMD_COMPONENT_ARM_DISARM (400)` → arm/disarm |
| COMMAND_LONG | 76 | `MAV_CMD_DO_FLIGHTTERMINATION (185)` → 紧急终止飞行 |

配置项：`MAVLINK_SYS_ID = 1`，`MAVLINK_COMP_ID = 192`（Onboard Computer），心跳周期 1 s，链路超时 5 s。注释 `config.h` 中的 `MAVLINK_ENABLED` 可将全部函数退化为空桩。

## 八、安全机制

### 8.1 状态机

```
上电 → [SAFETY_INIT] ──POST 通过──► [SAFETY_NORMAL]
             │                            │  ▲
             └──POST 失败──┐              │  │ 故障清除
                           ▼              ▼  │
                      [SAFETY_ESTOP] ◄─ [SAFETY_DEGRADED]
```

### 8.2 急停触发条件

| 条件 | 阈值 |
|------|------|
| 接收机信号丢失 | 任一通道 <800 或 >2200；或 CH1/CH2 连续 2 s 不变（仅地面模式累计） |
| 反馈失控 | 位置误差 >500 且轮子朝误差反方向滚动，持续 1 s |
| 看门狗超时 | 3000 ms 未喂狗 → 硬件复位 |
| 手动触发 | `Safety::triggerEStop(reason)` |

急停动作：四轮**短路制动**（防溜坡）、关闭清洁电机、复位 PID 与清扫状态机、向飞控发送 disarm。

### 8.3 恢复手势

急停后需遥控器执行固定手势复位：**CH9 先拉低（<1200，飞行）→ 再拨高（>1700，地面）切换一次**。恢复时只清除瞬态故障位（倾角/堵转/位置超限/信号），保留硬件故障位，使未恢复的硬件故障能在下一周期重新触发降级。

### 8.4 上电自检（POST）

检查 4 个通道值是否落在 800–2200 有效区间、初始化看门狗；全部通道 ≈1500 时额外提示"接收机可能未连接"。任一通道越界 → 直接进入急停。

## 九、编译与烧录

需要 [PlatformIO](https://platformio.org/)（VS Code 插件或 CLI）。

```bash
# 编译
pio run

# 烧录
pio run --target upload

# 串口监视器 (115200)
pio device monitor
```

### ⚠️ `platformio.ini` 中的两条关键 `build_flags`

```ini
-DARDUINO_USB_MODE=0          # USB 走 USB-Serial-JTAG，app_main 才会调用 Serial.begin()
-DARDUINO_USB_CDC_ON_BOOT=1   # Serial0 从物理 UART0(GPIO43/44) 改到 USB
```

**两行缺一不可**。否则 `Serial0`（UART0，115200）与 `Serial1`（UART1，921600）会同时占用 GPIO43/44，导致串口输出全部乱码。

## 十、调试输出

USB 串口（115200）每 500 ms 输出一行状态，用于现场核查固件版本与实时数据：

```
PID gains -> kpP:0.70 kpV:1.20 kiV:0.10 kdV:0.50  <- v2026-08-13
[Angle]2.3° [Mode]G [Safe]1 [CH]1500/1500/1800/1000 [Out]0/0
[Cnt]0/0 [Tgt]0/0 [Spd]0/0 [Mode2]1 [ff]0.00 [Auto]0 [Rows]0/6
[Safe] S:1 F:0x0
```

| 字段 | 含义 |
|------|------|
| `[Angle]` | 俯仰角（°），正值前倾 |
| `[Mode]` | `G` = 地面模式，`F` = 飞行模式 |
| `[CH]` | CH1 / CH2 / CH9 / CH10 脉宽（µs） |
| `[Out]` | 左右轮 PID 输出 PWM（−255~255） |
| `[Cnt]` / `[Tgt]` / `[Spd]` | 编码器计数 / 位置目标 / 每周期速度 |
| `[Mode2]` | 上位机下发的通信模式 |
| `[ff]` | 重力前馈淡入因子（0→1） |
| `[Auto]` / `[Rows]` | 清扫状态机状态 / 已完成行数 |
| `[Safe]` | 安全状态 `S:` 与故障掩码 `F:` |

开机首行会打印**当前 PID 增益**，用于确认烧录的固件与参数是否为最新版本。

## 十一、已知问题与注意事项

1. **重力前馈当前未生效**。[main.cpp](src/main.cpp) 的 `setup()` 中 `IMU::begin()` 前的 `bool` 关键字会遮蔽全局 `static bool imuOk`，导致主循环中 `if (imuOk)` 恒为 false，前馈与姿态更新被跳过。接回 MPU6050 时需去掉该 `bool` 才能恢复。
2. **倾角超限与堵转检测已注释**。[safety.cpp](src/safety.cpp) 中 `FAULT_OVER_TILT`、`FAULT_STALL_L/R`、`FAULT_IMU` 的检测逻辑当前处于注释状态（台架调试期间）。`config.h` 中的相关阈值已配置但不会被触发。
3. **`VL53L1X` 是遗留依赖**。红外测距模块代码已移除，但 `platformio.ini` 的 `lib_deps` 中仍保留 `pololu/VL53L1X@^1.0.0`，可安全删除。
4. **`src/v12_original.cpp.bak`** 为模块化重构前的单文件备份，`.bak` 后缀不参与编译。
5. **`config.h` 是参数的唯一权威来源**。根目录历史上存在一份 PID 调试指南，其中的增益数值（`kp_p = 1.2`、`kp_v = 8.5`、`ki_v = 1.2` 等）已被 2026-08-13 的修正取代，以本 README 与 `config.h` 为准。

## 十三、开发说明

- 所有源文件使用中文注释，注释中记录了大量调参依据与失败尝试（如"kpV 8.5 会 bang-bang 震荡"），修改参数前建议先阅读对应注释。
- 模块间通过 `config.h` 常量解耦，新增外设优先在 `config.h` 声明引脚，再在对应模块中引用。
- 控制回路中的共享状态读取一律走原子读（`Encoder::readPair`）或快照（`main.cpp` 中的 `rxCh*` 局部变量），避免 ISR 跨指令撕裂。
